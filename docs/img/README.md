# Capturas de Zalent

Las que se publican (README y web del portfolio). Todas con **datos de
ejemplo ficticios** (Ajustes → Datos → *Cargar datos de ejemplo*): nunca CVs
reales, porque en un repositorio público una captura con datos de una persona
es una filtración permanente.
